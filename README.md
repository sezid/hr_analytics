# HR Analytics Dashboard - Power BI Case Study 

This project demonstrates a comprehensive HR analytics dashboard created using Power BI for a fictitious software company, Atlas Labs. The dashboard provides insights into key HR metrics such as employee performance, attrition rates, and retention factors. The goal is to identify patterns that help the organization improve employee retention and make data-driven HR decisions.

This case study was completed as part of my learning journey on **DataCamp**.

## Key Features:

- **Advanced DAX Calculations**: Utilized DAX to create custom measures that identify trends in employee attrition.
- **Data Modeling**: Cleaned and structured the data using Power Query to prepare it for in-depth analysis.
- **Attrition Analysis**: Focused on understanding the factors that impact employee attrition and provided actionable insights.
- **Branded Power BI Report**: Designed a professional, branded report layout for Atlas Labs that enhances the presentation of insights.

## Tools Used:

- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query
- Data Modeling

## Dataset:

The dataset includes employee information such as age, tenure, performance ratings, department, and attrition status.

## How to Use:

1. Open the `hr_analytics.pbix` file in Power BI Desktop.
2. Interact with the dashboard using slicers for department, age, and tenure to explore trends.
3. Analyze key metrics such as employee attrition and retention factors.
